# 表記ルールと用語集

記事とトピックを書くときの表記の決まり。新聞の一般的な表記に近づけ、サイトの中でそろえることを目的にする。迷ったら、このファイルに決まりを足してから書く。

## 文体

- 常体（だ・である）で書く。「です・ます」は編集方針などのサイト案内のページだけ。
- 1 文は短く。一つの文に一つのことを書く。
- 編集部の評価を表す言葉（「異例の」「注目の」「物議を醸す」など）は、事実で裏付けられるときだけ使う。

## 人名・肩書

- 初出はフルネームと肩書（「沖縄県の古謝玄太知事」「京都大学教授の岸政彦氏」）。2 回目からは姓に「氏」（「古謝氏」）。
- 肩書は、その出来事があった時点のもの。
- 敬称は「氏」にそろえる。
- 年齢は、選挙の候補者など必要なときだけ書く。「（42）」の形で、その時点の年齢。
- 読みにくい名前は、トピックの本文の初出に読みを書く（例: 古謝玄太（こじゃ・げんた））。

## 数字・日付・時刻

- 数字は算用数字。大きな数は「42万3000票」「3兆円」のように万・億・兆で区切る。
- 割合は「%」。小数は出典の桁に合わせる。
- 日付は「9月13日」。年が明らかでないとき、年をまたぐときは「2026年9月13日」。曜日は書かない。
- 時刻は「午後8時」のように午前・午後で書く。
- 年表（`timeline`）の日付は `YYYY-MM-DD`。日が分からなければ `YYYY-MM`。

## 記号

- かっこは全角の（）、引用は「」、引用の中の引用は『』。書名は『』。
- 英数字は半角。

## 政党・団体の略称

初出から略称でよい: 自民党、立憲民主党、日本維新の会（2 回目から維新）、公明党、国民民主党、共産党、れいわ新選組、社民党、参政党、日本保守党、沖縄社会大衆党（2 回目から社大党）。

## 用語集

立場によって呼び方が分かれる言葉は、ここで決めた言い方を地の文に使い、別の言い方は使っている人の言葉として「」で引く。

### 沖縄の基地

| 地の文で使う | 説明・ほかの言い方 |
| --- | --- |
| 普天間飛行場（宜野湾市） | 米海兵隊の飛行場。正式には「普天間飛行場」。「普天間基地」とも呼ばれる。 |
| 辺野古移設 | 普天間飛行場の代わりの施設を名護市辺野古に造る計画。政府は「普天間飛行場代替施設」と呼び、反対する人々や沖縄の地元紙の多くは「新基地建設」と呼ぶ。地の文では「辺野古移設」「移設計画」「移設工事」を使い、初出で「普天間飛行場（宜野湾市）の名護市辺野古への移設」と説明する。 |
| 大浦湾 | 辺野古の北側の海域。軟弱地盤があり、地盤改良工事が行われている。 |
| 設計変更 | 軟弱地盤の改良のために国が申請した埋め立て計画の変更。県は承認せず、国が 2023 年に代執行で承認した。 |
| 「オール沖縄」 | 辺野古移設に反対する政党・団体などでつくる勢力の呼び名。地の文で使うときは「」を付け、初出で説明する。 |
| 在沖米軍、在日米軍 | 「米軍基地」は沖縄にある米軍の施設全般。「米軍専用施設」は自衛隊と共用しない施設（面積の割合を言うときはこちら）。 |
| 日米地位協定 | 在日米軍の法的な地位を定める協定。2 回目から「地位協定」。 |
| 南西諸島の防衛力強化 | 政府の言い方は「南西地域の防衛体制の強化」。「南西シフト」は報道などでの通称で、地の文で使うときは「」を付ける。 |
| 在沖米軍トップ | 在沖米軍の調整役を務める米海兵隊の司令官（2026年10月時点はベンジャミン・ワトソン中将。第3海兵遠征軍司令官を兼ねる）。媒体によって「四軍調整官」「沖縄地域調整官」と呼び方が分かれるので、地の文では「在沖米軍トップの〇〇中将」と書く。 |

### 事件・事故

| 地の文で使う | 説明・ほかの言い方 |
| --- | --- |
| 〜の疑いで逮捕、容疑者 | 起訴される前の段階。「〜した疑いがある」「〜容疑で逮捕」と書き、本人が容疑を認めているか否認しているかを併せて書く。罪を犯したと決めつける書き方をしない。 |

### 訴訟

| 地の文で使う | 説明・ほかの言い方 |
| --- | --- |
| 提訴した、訴えた | 民事訴訟を起こすこと。刑事の「告訴」「告発」と混同しない。 |
| 原告、被告 | 民事訴訟で訴えた側、訴えられた側。「被告」は刑事の「被告人」とは別。民事の被告を悪く見せる書き方をしない。 |
| 口頭弁論、期日 | 法廷で開かれる審理と、その日。 |
| 名誉毀損 | 「毀損」は漢字で書く。 |
| アカデミック・ハラスメント | 初出は「アカデミック・ハラスメント（アカハラ）」。告発の段階では「〜を受けたと主張している」と書く。 |
